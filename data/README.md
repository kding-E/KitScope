# Data Directory

`data/smoke/` contains a lightweight fixture for checking the local
installation.

Place the KitScope dataset bundle at:

```text
data/kitscope-release/
```

Dataset URL:

```text
https://t3.znas.cn/rxHtGmUHCgg
```

KitScope expects `pcap/`, `har/`, `json/`, `screenshots/`,
`static_features/`, `manifest.jsonl`, and `splits/url_group_weights.csv`
under that release directory.
